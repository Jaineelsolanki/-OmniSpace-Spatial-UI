# OmniSpace — Spatial Operating System UI

A spatial user interface design project exploring an intuitive, interactive and visually organised operating system experience for spatial computing environments.

---

## Project Overview

OmniSpace explores how users can interact with applications, tools and digital workspaces in a 3D spatial environment.

The project focuses on floating interfaces, contextual controls, reusable components and multiple spatial layout modes while considering usability, visual consistency and ergonomic placement.

## Project Objectives

- Design a spatial operating system interface.
- Develop a reusable UI component library.
- Create compact and expanded workspace layouts.
- Establish a consistent Z-axis and depth hierarchy.
- Define gesture-based interaction patterns.
- Develop a 3D spatial interface prototype.
- Prepare design specifications and developer handoff documentation.

## Testing and Limitations

Figma prototype interactions were manually checked in Present mode.

The Spline project includes a 3D spatial interface and a desktop pointer-based interaction layer. Actual headset gaze tracking, hand tracking and pinch recognition require a supported XR runtime and have not been validated.

Distance bands, scaling values and ergonomic placements are design assumptions that require further user validation.
