# OmniSpace — Spatial Operating System UI

A spatial user interface design project focused on creating an intuitive, interactive and visually consistent operating system experience for spatial computing environments.

## Project Overview

OmniSpace explores how users can interact with applications, tools and digital workspaces in a 3D spatial environment.

The project focuses on designing floating interfaces, contextual controls, reusable components and different spatial layout modes while maintaining usability, visual clarity and ergonomic considerations.

## Objectives

- Design a complete spatial operating system interface.
- Create reusable UI components with consistent visual states.
- Explore compact and expanded spatial layouts.
- Establish a consistent Z-axis and depth hierarchy.
- Define gesture-based interaction patterns.
- Develop a 3D spatial interface prototype.
- Prepare design specifications and developer handoff documentation.

## Key Features

### 1. Spatial Interface
A central spatial workspace with application navigation, project cards, toolbar and contextual inspector.

### 2. Compact and Expanded Layouts
Two interface arrangements designed for different spatial workspace requirements.

### 3. Reusable Component Library
A component system containing:
- Buttons
- Toolbar icons
- Spatial panels
- Sliders
- Hover, selected and disabled states

### 4. Spatial Behaviour
Documentation covering:
- Z-axis hierarchy
- Distance-based scaling concepts
- Ergonomic placement
- Gesture-to-component mapping

### 5. Interactive Prototype
A prototype demonstrating:
- Hover and selection feedback
- Navigation interactions
- Toolbar actions
- Panel controls
- Opacity adjustment
- Compact and expanded layout demonstrations

**Prototype limitation:** The Spline interaction layer uses desktop mouse simulation. Actual headset gaze tracking and hand-pinch recognition require a supported XR runtime and have not been validated.
